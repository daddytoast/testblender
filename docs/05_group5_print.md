# Группа 5 — «Печать» (`NK.5_Печать`)

Файл-источник: `scripts/build_group5_print.py`
Проверка: `scripts/verify_group5.py`
Готовый файл: `builds/group5_print.blend` (Группа 1→2→3→4→5 в одном модификаторе)

## Назначение

Последняя группа: режет переднюю/заднюю половину (уже с закладными из
Группы 4) на печатаемые сегменты, если высота накладки превышает
рабочую зону принтера, и делает стык менее заметным наклоном плоскости
разреза вместо ровного горизонтального кольца.

**Рабочая зона по умолчанию — Elegoo Centauri Carbon: 256×256×256 мм**
(подтверждено официальными характеристиками принтера). При длине
накладки по умолчанию (350 мм) это означает **2 сегмента** на
каждую половину.

## Архитектура: 2 вложенные группы

```
NK.5_Печать (верхний уровень, узлы 5.xx)
 │
 ├─ считает, сколько сегментов нужно (высота / рабочая зона принтера)
 │
 └─ вызывает до 2 раз (Перед, Зад) → NK.5a_Разрез_с_крышкой (узлы 5a.xx)
                                          │
                                          └─ вызывает 2 раза → NK.5b_Крышка_среза (узлы 5b.xx)
```

## 1) `NK.5b_Крышка_среза` — закрыть произвольный срез "крышкой"

После Boolean-разреза (Группа 3/4 это уже делали для верха/низа/швов
оболочки через явные "мосты" между известными контурами) на **новом,
заранее не известном** месте среза открытые рёбра нужно закрыть
как-то иначе — мы не знаем заранее форму сечения в производной
точке. Решение: найти открытые рёбра (те же признаки "дыры", что и в
проверках замкнутости Группы 3/4), превратить их в кривую и залить.

| № | Узел | Формула/роль |
|---|---|---|
| `5b.01` | Group Input | `Mesh` |
| `5b.02` | `Edge Neighbors` | число граней на каждом ребре |
| `5b.03` | `Compare` (INT, NOT_EQUAL 2) | ребро "открытое" |
| `5b.04` | `Mesh to Curve` (Selection=`5b.03`) | открытые рёбра → контур(ы)-кривая(ые) |
| `5b.05` | `Fill Curve` (**mode=NGONS**) | залить контур(ы) плоской крышкой |
| `5b.06` | `Join Geometry` | исходный меш + крышка |
| `5b.07` | `Merge by Distance` (0.01мм) | сварить крышку с краем меша |

**Почему `NGONS`, а не `TRIANGLES`:** срез полой стенки даёт ДВА
контура одновременно — внешний и внутренний (как в Группе 3). `Fill
Curve` в режиме NGONS корректно распознаёт вложенный внутренний
контур как ДЫРКУ, а не заливает его сплошняком — то есть результат
это именно кольцо нужной толщины стенки, а не сплошной диск. Это
критично: если бы дырка заливалась, деталь превратилась бы из полой
в сплошную ровно на срезе.

Техника проверена отдельным тестом на полой трубе (аналог стенки
накладки: внешний цилиндр минус внутренний, разрез посередине) ДО
сборки всей группы: 0 открытых рёбер, положительный
`bmesh.calc_volume(signed=True)` — то есть и замкнутость, и
корректная ориентация нормалей на новой крышке.

## 2) `NK.5a_Разрез_с_крышкой` — разрез одной плоскостью

Берёт `Точка_на_плоскости` + `Нормаль_плоскости` (плоскость не
обязательно горизонтальная — см. `Наклон_шва_град` ниже), режет
геометрию на 2 части через тот же приём, что и разрез перед/зад в
Группе 3/4 (`Boolean INTERSECT` с гигантским кубом-полупространством,
повёрнутым по нормали через `Align Euler to Vector`), и закрывает
обе части через `NK.5b`.

| Раздел | № узлов | Что делает |
|---|---|---|
| 1. Два куба-полупространства | `5a.02-09` | куб 4000мм повёрнут по нормали (`Align Euler to Vector`), два экземпляра — по разные стороны от `Точка_на_плоскости` |
| 2. Разрез + крышки | `5a.10-13` | `Boolean INTERSECT` (**оба операнда в Mesh 2** — см. Группу 4 про этот баг Blender) → `NK.5b` на каждую часть |

## 3) `NK.5_Печать` — верхний уровень

### Входные параметры

| Сокет | Тип | По умолч. | Диапазон | Смысл |
|---|---|---|---|---|
| `Перед`, `Зад` | Geometry | — | — | Выходы Группы 4 |
| `Точка_A`, `Точка_B` | Vector | — | — | Выходы Группы 1 |
| `Печать_X_мм` / `Y` / `Z` | Float | 256 / 256 / 256 | 150–400 | Рабочая зона принтера (Elegoo Centauri Carbon по умолчанию) |
| `Зазор_реза_мм` | Float | 5.0 | 0–15 | Запас, чтобы сегмент точно влез |
| `Наклон_шва_град` | Float | 12.0 | 0–25 | Наклон плоскости разреза — см. ниже |

### Раздел 1 — сколько сегментов нужно (макс. 2 в этой версии)

| № | Узел | Формула |
|---|---|---|
| `5.02` | `Vector Math` DISTANCE | H = расстояние `Точка_A`–`Точка_B` |
| `5.03` | `Math` SUBTRACT | usable = `Печать_Z_мм` − `Зазор_реза_мм` |
| `5.04-07` | `Math` DIVIDE→CEIL→MIN(2)→MAX(1) | `Число_сегментов` = `ceil(H/usable)`, зажато в [1, 2] |
| `5.08` | `Float to Int` | → Int |
| `5.09` | `Compare` (INT, GREATER_EQUAL 2) | нужен ли вообще разрез |

### Раздел 2 — плоскость разреза: высота + наклон

Высота разреза берётся **посередине** (`H / Число_сегментов`), плоскость
**наклонена** вокруг оси Y на `Наклон_шва_град` — то есть высота
разреза плавно меняется от медиальной стороны к латеральной, вместо
ровного горизонтального кольца.

| № | Узел | Формула |
|---|---|---|
| `5.10-11` | `Math` DIVIDE + `Combine XYZ` | `Точка_на_плоскости` = (0, 0, H/Число_сегментов) |
| `5.12-14` | `Math` RADIANS + `Combine XYZ` + `Euler to Rotation` + `Rotate Vector` | `Нормаль_плоскости` = поворот (0,0,1) на `Наклон_шва_град` вокруг Y |

**Почему наклон, а не ровный срез:** идеально горизонтальное кольцо
читается глазом как явный "технологический" шов ("тут деталь
напечатана в 2 части"). Наклонная плоскость (стандартный приём в
костюмерии/реквизите для скрытия сегментных стыков) и визуально
менее очевидна, и даёт БОЛЬШУЮ площадь склейки (прочнее шов) за счёт
того, что режет не по кратчайшему пути через стенку, а по диагонали.

### Раздел 3-4 — разрез + запасной вариант "без разреза"

`5.15-16` — `NK.5a` на `Перед` и на `Зад`. `5.17-20` — 4 узла
`Switch` (Geometry): если сегмент не нужен (`Число_сегментов`==1) —
на выходе целая деталь и пустая геометрия вместо второго сегмента;
если нужен — нижняя/верхняя часть разреза.

**Ещё один баг Blender, найденный здесь (третий за проект):** у
`GeometryNodeSwitch` при `input_type='GEOMETRY'` булево условие нужно
подключать в сокет **`Switch_001`**, а НЕ в `Switch` (хотя в
интерфейсе Blender показывает один общий переключатель!). Похоже,
внутри узла условие для "простых" типов (Float/Int/Bool/Vector/Color/
String) и для "объектных" типов (Geometry/Object/Collection/Texture/
Material/Image) технически разделено на 2 независимых сокета,
синхронизируемых только через UI. Обнаружено минимальным тестом (два
куба разного размера, `Switch=True` через `Switch` упорно выбирал
`False`-ветку) до того, как стало понятно, почему `Перед_Верх`
всегда получался пустым, а `Перед_Низ` — не разрезанным. Все 4
переключателя в этой группе используют `Switch_001`.

### Раздел 5 — итог: VIS, проверки, отчёт

`5.21` — `VIS_Вместе` (join всех 4 выходов; пустые ничего не
добавляют). `V5.1-V5.7` — проверка замкнутости всех 4 выходов (тем
же приёмом Edge Neighbors, что в Группах 3-4); **пустая геометрия
тривиально проходит проверку** (сумма по 0 элементам = 0). `5.22-23`
— текстовый отчёт.

## Известные упрощения и ограничения

- **Максимум 2 сегмента на половину** в этой версии (не полноценный
  Repeat Zone на произвольное число разрезов). При умолчаниях (длина
  350мм, принтер 256мм) это ровно то, что нужно. Если ваша накладка
  значительно длиннее рабочей зоны принтера (нужно 3+ сегмента) —
  либо увеличьте `Печать_Z_мм` под факт возможностей вашего принтера
  (если он позволяет печать по диагонали стола длиннее паспортной оси
  — куб 256×256×256 даёт диагональ по основанию до ~362мм), либо
  разрежьте один из сегментов вручную в Blender тем же приёмом
  (`NK.5a_Разрез_с_крышкой` можно вызвать ещё раз вручную).
- Закладные (хомуты/магниты) Группы 4 должны попадать ЦЕЛИКОМ в один
  сегмент — если высота разреза случайно пройдёт прямо через бобышку
  хомута/магнита, срез и крышка всё равно будут построены корректно
  (проверено — это обычный Boolean на сложной форме), но сама
  деталь-бобышка окажется разрезанной пополам между двумя сегментами,
  что нежелательно с инженерной точки зрения. Подбирайте
  `Хомут1/2_высота_доля_от_колена` (Группа 4) так, чтобы не совпадать
  с `H/Число_сегментов` (Группа 5) — либо ниже, либо выше середины.
- `Печать_X_мм`/`Печать_Y_мм` пока не используются в расчётах (в этой
  версии режем только по высоте Z, поперечные размеры накладки — до
  ~130мм — всегда меньше рабочей зоны 256мм принтера). Оставлены как
  входы на будущее (для варианта с печатью под углом/лёжа).

## Как проверить самостоятельно в Blender 5.1

1. Открыть `builds/group5_print.blend`, объект `NK_Group5_Demo`.
2. В модификаторе — пять вложенных `Group`: Группа 1→2→3→4→5.
3. Покрутите `Печать_Z_мм` (например, увеличьте до 400 — сегментов
   станет 1) и `Наклон_шва_град` — форма и число сегментов должны
   пересчитываться на лету.
4. Переключите выход модификатора на `Перед_Низ`/`Перед_Верх` по
   отдельности, чтобы увидеть каждый сегмент для экспорта STL.
5. Для печати: экспортируйте каждый сегмент (`Перед_Низ`,
   `Перед_Верх`, `Зад_Низ`, `Зад_Верх` — до 4 STL-файлов) через
   File → Export → STL, с масштабом экспорта = 1 (единицы уже в мм,
   см. `docs/00_overview.md`).

## Проект завершён — что дальше

Это была последняя из 5 запланированных групп. Полная цепочка
Группа 1 (Ось) → Группа 2 (Профиль) → Группа 3 (Оболочка) → Группа 4
(Закладные) → Группа 5 (Печать) даёт на выходе до 4 STL-готовых
сегментов (`Перед_Низ`, `Перед_Верх`, `Зад_Низ`, `Зад_Верх`),
полностью параметрических, с автоматической проверкой замкнутости и
корректной ориентации нормалей на каждом шаге.

Естественные следующие шаги (не запрошены в этой сессии, но логичны
для дальнейшего развития проекта):
- калибровочная печать первого сегмента и подгонка допусков
  (зазор гайки/винта/магнита, посадка на трубку) под реальный принтер
  и филамент;
- снятие реальных мерок конкретного пациента вместо средних
  анатомических диапазонов (все параметры уже вынесены наружу — это
  просто подстановка других чисел);
- опционально: полноценный Repeat Zone в Группе 5 для произвольного
  числа сегментов, если понадобится печатать более длинные сегменты
  конечности (бедро, предплечье и т.п.) на этом же принтере.
