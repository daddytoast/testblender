# Группа 2 — «Профиль» (`NK.2_Профиль`)

Файл-источник: `scripts/build_group2_profile.py`
Проверка: `scripts/verify_group2.py`
Готовый файл: `builds/group2_profile.blend` (Группа 1 → Группа 2 нанизаны в одном модификаторе)

## Назначение

Строит **семейство поперечных сечений** голени вдоль оси из Группы 1:
для каждой из N точек оси — своё "кольцо" из M точек, форма и размер
которого меняются по высоте T (0 = лодыжка, 1 = колено):

- общий размер кольца интерполируется между **2 заданными обхватами**
  (ровно как протезист снимает мерки — сантиметровой лентой в двух
  местах);
- спереди — подрезка по бокам от гребня большеберцовой кости (ближе
  к лодыжке — заметнее, ближе к колену — мягче, там больше тканей);
- сзади — выступ, имитирующий икроножную мышцу, с пиком на заданной
  высоте и плавным затуханием вверх/вниз.

Эта группа **не** строит сплошную оболочку (это Группа 3) — она
готовит "сырьё" для лофта: облако точек и/или набор замкнутых колец,
уже полностью описывающих форму на каждой высоте.

## Ключевая техника: как сделать РАЗНУЮ форму кольца на каждой высоте без циклов

В отличие от Группы 1, здесь необходимо посчитать **разную геометрию
для каждой из N точек оси** — а обычное `Instance on Points`
позволяет только одинаково масштабировать/поворачивать одну и ту же
инстансированную геометрию, не деформируя её индивидуально. Вместо
цикла (Repeat Zone) использован приём, стандартный в среде Geometry
Nodes для таких задач — "инстансировать → развернуть (Realize) →
атрибуты родительской точки автоматически достаются каждой точке её
инстанса":

1. На точках **оси** (Group Input `Ось_кривая`) "запекаем" через
   `Store Named Attribute`: высоту `ring_T`, позицию `ring_center`,
   номер точки `ring_index` (секция 2).
2. Готовим болванку кольца — окружность радиуса 1 (`Mesh Circle`), и
   на ЕЁ точках запекаем `dir` = их собственная позиция, т.е. единичное
   направление (секция 3).
3. `Instance on Points`: инстансируем болванку кольца на каждую точку
   оси (секция 4).
4. `Realize Instances`: разворачивает N инстансов из M точек каждый в
   плоское облако из N×M точек. **Атрибуты, запечённые на точках оси
   (`ring_T`, `ring_center`, `ring_index`), автоматически "спускаются"
   на все M точек своего кольца** — так каждая из N×M точек узнаёт, на
   какой она высоте и где центр её кольца, а `dir` (запечённый на
   болванке) остаётся её персональным направлением.
5. Дальше — обычная работа с полями (без единого цикла): читаем через
   `Named Attribute` эти 4 запечённых значения и обычной арифметикой
   считаем нужный радиус `R(dir, ring_T)`, затем переставляем точку в
   `центр + dir * R` (`Set Position`).

Этот приём был отдельно проверен тестовым скриптом **до** сборки всей
группы (см. историю разработки) — на 3 точках оси с 4-точечным
кольцом атрибут родителя корректно "спускается" на все точки кольца.

## Система координат для расчёта формы

`dir` — единичный вектор в плоскости XY (см. Группу 1: X = мед/лат,
Y = перед/зад). Направление считывается прямо из позиций точек
окружности-болванки, без единой тригонометрической функции:

- `dir.y = +1` → точка ровно спереди (гребень);
- `dir.y = -1` → точка ровно сзади (икра);
- `dir.x = ±1` → точки строго сбоку (медиально/латерально), там обе
  "особые" добавки (гребень/икра) равны нулю.

### Секция 5 — базовый радиус R_base(T)

Интерполяция между двумя обхватами линейная, с зажимом за пределами
(`Map Range`, Clamp=True) — то есть выше верхней или ниже нижней
контрольной точки радиус не растёт дальше, а держится на уровне
ближайшей заданной точки.

| № | Узел | Формула/вход | Выход |
|---|---|---|---|
| `2.10` | `Math` SUBTRACT | `1 - Точка1_доля_от_колена` | T1 → `2.15.From Min` |
| `2.11` | `Math` SUBTRACT | `1 - Точка2_доля_от_колена` | T2 → `2.15.From Max` |
| `2.12` | `Math` DIVIDE | `Обхват_Точка1_мм / 2π` | R1 → `2.15.To Min` |
| `2.13` | `Math` DIVIDE | `Обхват_Точка2_мм / 2π` | R2 → `2.15.To Max` |
| `2.14` | `Named Attribute` (Float) | Name="ring_T" | `ring_T` → `2.15.Value`, и в секции 6/7 |
| `2.15` | `Map Range` | Value=`2.14`, диапазон `2.10..2.11` → `2.12..2.13`, Clamp=True | `R_base(T)` → `2.35` |

### Секция 6 — гребень большеберцовой кости (перед, +Y)

`crest_indent(θ) = 4·w_front·(1−w_front)`, где `w_front=max(dir.y,0)`
— парабола, равная нулю точно спереди (`dir.y=1`) и по бокам
(`dir.y=0`), с максимумом (=1) где-то между ними. Именно этот "провал
по краям, а не в центре" визуально читается как заострение гребня.

| № | Узел | Формула | Выход |
|---|---|---|---|
| `2.16` | `Named Attribute` (Vector) | Name="dir" | `dir` → `2.17`, и в `2.38` |
| `2.17` | `Separate XYZ` | `dir` → X, Y | Y → `2.18`,`2.26` |
| `2.18` | `Math` MAXIMUM | `max(dir.Y, 0)` | w_front → `2.19`,`2.20` |
| `2.19` | `Math` SUBTRACT | `1 - w_front` | → `2.20` |
| `2.20` | `Math` MULTIPLY | `w_front*(1-w_front)` | → `2.21` |
| `2.21` | `Math` MULTIPLY | `*4` (нормировка пика в 1.0) | crest_indent → `2.24` |
| `2.22` | `Mix` (Float) | `mix(У_лодыжки, У_колена, ring_T)` | острота(T) → `2.23` |
| `2.23` | `Math` MULTIPLY | `острота(T) * Гребень_глубина_мм` | depth(T) → `2.24` |
| `2.24` | `Math` MULTIPLY | `depth(T) * crest_indent` | crest_raw → `2.25` |
| `2.25` | `Math` MULTIPLY | `crest_raw * (-1)` | **term_crest** → `2.35` |

### Секция 7 — икроножная мышца (зад, -Y)

`falloff(T) = clamp(1 - |T - T_икра| / Икра_ширина_доля, 0, 1)` —
треугольная "шапочка", 1 точно на высоте икры, линейно спадает до 0 на
расстоянии `Икра_ширина_доля` от неё в обе стороны.

| № | Узел | Формула | Выход |
|---|---|---|---|
| `2.26` | `Math` MULTIPLY | `dir.Y * (-1)` | → `2.27` |
| `2.27` | `Math` MAXIMUM | `max(-dir.Y, 0)` | w_back → `2.33` |
| `2.28` | `Math` SUBTRACT | `1 - Высота_икры_доля_от_колена` | T_икра → `2.29` |
| `2.29` | `Math` SUBTRACT | `ring_T - T_икра` | diff → `2.30` |
| `2.30` | `Math` ABSOLUTE | `\|diff\|` | → `2.31` |
| `2.31` | `Math` DIVIDE | `\|diff\| / Икра_ширина_доля` | норм. → `2.32` |
| `2.32` | `Math` SUBTRACT (use_clamp=True) | `clamp(1 - норм., 0, 1)` | falloff(T) → `2.34` |
| `2.33` | `Math` MULTIPLY | `Икра_выступ_мм * w_back` | → `2.34` |
| `2.34` | `Math` MULTIPLY | `(Икра_выступ*w_back) * falloff(T)` | **term_calf** → `2.36` |

### Секция 9 — кольца в кривые + временная визуализация

**Важно (грабли, на которые я сам наступил при сборке):**
`Points to Curves` принимает только геометрию типа "облако точек"
(Point Cloud) — если подать вершины меша напрямую, узел молча вернёт
0 точек без ошибки. Поэтому перед ним обязательна конвертация
`Mesh to Points` (узел `2.41b`).

| № | Узел | Вход | Выход | Параметры |
|---|---|---|---|---|
| `2.41` | `Named Attribute` (Int) | Name="ring_index" | → `2.42.Curve Group ID` | |
| `2.41b` | `Mesh to Points` | `Mesh`←`2.40` | `Points`→`2.42` | обязательная конвертация типа геометрии |
| `2.42` | `Points to Curves` | `Points`←`2.41b`, `Curve Group ID`←`2.41` | `Curves`→`2.43` | группирует точки по ring_index в N кривых |
| `2.43` | `Set Spline Cyclic` | `Geometry`←`2.42`, Cyclic=True | **`Кольца_кривые`** | замыкает каждое кольцо |
| `2.44` | `Curve Circle` | Radius=1.2мм | → `2.45` (Profile) | болванка для VIS-трубок |
| `2.45` | `Curve to Mesh` | `Curve`←`2.43`, `Profile`←`2.44` | **`VIS_Кольца`** | |

## Известные упрощения

- Добавка радиуса икры — это скалярная добавка вдоль `dir`, поэтому
  она немного "раздувает" сечение не строго по Y, а по всей задней
  дуге (в т.ч. слегка по X у боковых точек). Анатомически это не
  проблема (икра и правда объёмная, не плоская), но если понадобится
  чисто сагиттальный выступ — можно домножить `term_calf` на `w_back`
  в более высокой степени (например, `w_back^2`), сузив зону влияния.
- Гребень и икра считаются симметричными медиально/латерально
  (форма зависит только от `dir.y`, не от знака `dir.x`) — среднее
  анатомическое упрощение, соответствует ТЗ ("средние анатомические
  диапазоны").
- Между двумя контрольными точками обхвата — линейная интерполяция.
  Реальная голень чуть более "выпуклая" по кривой обхвата, но для
  первой версии (и с учётом того, что икра уже даёт свой отдельный
  выступ) линейного приближения достаточно.

## Как проверить самостоятельно в Blender 5.1

1. Открыть `builds/group2_profile.blend`.
2. Выбрать объект `NK_Group2_Demo` — в модификаторе будет виден узел
   `Group` `NK.1_Ось`, за ним `Group` `NK.2_Профиль` (это заготовка
   будущего `NK.Master`).
3. Покрутить `Гребень_глубина_мм`, `Икра_выступ_мм`,
   `Обхват_Точка1_мм` / `Точка2_мм` — стопка колец должна на лету
   менять и толщину, и форму сечения.
4. Зайти внутрь группы `NK.2_Профиль` (Tab) — весь граф разложен по
   пронумерованным рамкам 2..11, точно как в таблицах выше.
